# LIBANON4KPRO Android Studio Project

مشروع Android Studio جاهز لتطبيق IPTV MVP.

## الميزات الحالية
- إضافة Playlist عبر M3U URL
- تحميل وتحليل القنوات من ملف M3U
- حفظ البيانات محليًا باستخدام Room
- عرض القنوات في قائمة
- تشغيل القنوات عبر Media3 ExoPlayer
- إضافة/إزالة قناة من المفضلة
- شاشة مفضلة بسيطة
- شاشة إعدادات أساسية

## التشغيل
1. افتح المشروع في Android Studio.
2. انسخ `local.properties.example` إلى `local.properties` وحدد `sdk.dir` الصحيح.
3. اعمل Gradle Sync.
4. شغّل التطبيق.

## ملاحظات
- هذه نسخة MVP أولية.
- لا تتضمن بعد Xtream أو EPG أو Movies/Series.
